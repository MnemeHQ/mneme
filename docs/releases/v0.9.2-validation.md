# v0.9.2 — Release Validation Evidence

Recorded 2026-09-21. This document captures the release-readiness and
post-publication evidence for `mneme-hq==0.9.2`. The release completes the
Decision MCP tool documentation work: every input-schema property now has a
description, sibling-tool routing is explicit, search filter combination
semantics are documented, batch provenance is explained, and empty
applicability inputs have defined behavior. Runtime and protocol semantics are
unchanged.

## Public-package Decision MCP verification

A fresh Python 3.12 environment outside the checkout installed
`mneme-hq[mcp]==0.9.2` from public PyPI with no cache. A real MCP stdio client
connected to the installed `mneme decision-mcp` executable and listed the
published tool schemas.

- Installed package version: `0.9.2`.
- Tool count: exactly the frozen six-tool surface.
- Every top-level input-schema property has a non-empty description.
- Every nested `$defs` property has a non-empty description.
- `decision.search` exposes and documents all six filters: `query`,
  `proposal_status`, `canonical_lifecycle_status`, `producer_name`,
  `source_reference`, and `origin_classification`.
- Published top-level descriptions include the expected routing and semantic
  guidance: `get` vs `search`, `trace` vs `get`, single vs batch proposal,
  search AND semantics, and empty-input behavior for `applicable_to`.
