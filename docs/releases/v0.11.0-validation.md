### Release-prep PR checks

Release-prep PR [#759](https://github.com/MnemeHQ/mneme/pull/759) passed
every check bound to its reviewed head `bc4df13c` before merge: gate (PR
battery), `mneme check --mode warn`, `mneme trusted gate`, architecture
documentation, encoding, install-command, and execution provenance.

The trusted gate had failed on the two earlier heads (`89b7876a`,
`6d911d7d`). Editing `docs/integrations/adr-import.md` put that whole file in
scope, and it contained the ADR-005 forbidden literal as a documentation
example. The example was reworded in `bc4df13c` without changing its
meaning.

### Architecture verification

`scripts/check_architecture_docs.py` passed on the release-prep state. The
semantic review found stale statements in `docs/architecture/README.md`
(DG1B1 described as charter-gated, ADR-031 as implementation pending,
ADR-032/033/034 missing from the map) and in
`docs/integrations/adr-import.md` (the pre-write gate described as never
evaluating numeric rules, which G2-1 changed for new-file `Write`). #759
corrected both.

### Benchmark battery

unchanged since `v0.10.0`. `enforcer.py` changed (#469 DG1E evidence
