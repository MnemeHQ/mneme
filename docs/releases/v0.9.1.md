# mneme-hq 0.9.1

**MCP Registry discovery metadata for the Decision MCP server.**

This patch release adds the public metadata needed to register Mneme's local
Decision MCP server with the official MCP Registry. It does not change Decision
MCP tools, authority semantics, retrieval, enforcement, or the Architecture
Audit contract.

## Added

* `server.json` describing the public `io.github.MnemeHQ/mneme` MCP server and
  its PyPI distribution.
* The MCP Registry PyPI ownership marker in the package README.
* A regression test that keeps Registry server and package versions aligned
  with `pyproject.toml`.

## Compatibility

* No runtime or protocol behavior changes.
* The six frozen Decision MCP tools are unchanged.
* Proposal acceptance, rejection, activation, supersession, enforcement, and
  trusted evidence remain outside the MCP authority boundary.

## Install

```bash
pip install "mneme-hq[mcp]==0.9.1"
```

Then start the local stdio server:

```bash
mneme decision-mcp
```
